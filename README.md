# 🎨 Expo Basquiat - Site Web Interactif

## 📌 À propos du projet

**Expo Basquiat** est un site web fictif présentant une exposition d'art inspirée par l'univers de Jean-Michel Basquiat. Ce projet combine deux objectifs :

1. **Présenter une exposition fictive** : Un site web complet simulant une véritable exposition d'art où les visiteurs peuvent découvrir les détails, les tarifs, l'équipe et plus encore.
2. **Mise en pratique des compétences web** : Développé entièrement en **HTML**, **CSS** et **JavaScript**, ce projet est un exercice pédagogique visant à maîtriser les fondamentaux du développement web frontend.

## 🎯 Objectifs pédagogiques

Ce projet a été créé pour :
- ✅ Renforcer les compétences en **HTML structuré**
- ✅ Maîtriser le **CSS** pour le design et la mise en page
- ✅ Implémenter de l'interactivité avec **JavaScript**
- ✅ Créer une expérience utilisateur fluide et intuitive
- ✅ Démontrer la capacité à construire un site web fonctionnel

## 📂 Structure du projet

```
Expo_Basquiat/
├── Accueil.html          # Page d'accueil
├── Billet.html           # Gestion des billets d'entrée
├── Equipe.html           # Présentation de l'équipe
├── Expo2023.html         # Exposition 2023
├── Expo2024.html         # Exposition 2024
├── SITE_Expo.css         # Feuille de style principale
├── translate.js          # Fonctionnalités de traduction/interactivité
└── IMG/                  # Dossier contenant les images du projet
```

## 🌟 Fonctionnalités principales

- **Navigation multipage** : Accueil, expositions (2023 & 2024), billets, équipe
- **Design responsive** : Interface élégante et accessible
- **Interactivité** : Traduction et interactions dynamiques via JavaScript
- **Gestion de contenu** : Présentation complète d'une exposition fictive

## 🛠️ Technologies utilisées

| Technologie | Utilisation |
|-------------|-----------|
| **HTML5** | Structure et contenu |
| **CSS3** | Mise en page et design |
| **JavaScript** | Interactivité et traduction |

## 🚀 Comment utiliser

1. Clonez le repository
2. Ouvrez `Accueil.html` dans votre navigateur
3. Explorez les différentes pages du site
4. Testez les fonctionnalités interactives

## 📊 Apprentissages clés

Ce projet démontre la compréhension de :
- La structure logique d'un site web multi-pages
- Les principes du CSS moderne (layout, flexbox, grille, etc.)
- L'utilisation du JavaScript pour l'interactivité
- Les bonnes pratiques de développement frontend

## 🎓 Conclusion

Expo Basquiat est plus qu'un simple site fictif : c'est une preuve de concept montrant comment combiner créativité et compétences techniques pour créer une expérience web complète. Idéal pour un portfolio de développeur frontend ! 🚀
